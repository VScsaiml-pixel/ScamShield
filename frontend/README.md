# ScamShield AI — Frontend (React 19 + Vite)

Clean, professional, and explainable scam and phishing detection dashboard built with React 19, Vite, and Lucide React.

🌐 **Live Deployment:** [scamshield-4fae.vercel.app](https://scamshield-4fae.vercel.app/)

## Features
- **Message Threat Scanner**: Detects banking KYC phishing, UPI traps, digital arrest schemes, fake jobs, and parcel scams.
- **URL Phishing Inspector**: Safe-mode passive heuristic inspection of suspicious URLs.
- **Persistent Scan History**: Audit trail stored locally with full evidence inspection.
- **Cyber Scam Awareness Center**: Educational playbooks covering 10 common fraud vectors in India and the 6 credentials to never share.
- **Real-Time Security Dashboard**: Live charts, threat metrics, and recent scans overview.

## Scripts
```bash
npm install     # Install dependencies
npm run dev     # Start local development server (http://localhost:5173)
npm run build   # Production bundle in dist/
npm run preview # Preview production build locally
```
